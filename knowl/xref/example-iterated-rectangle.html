Example 2.1.7. Example I.

Calculate the double integral \(\displaystyle\int_0^2\!\!\int_0^2 \left(x^2 + y + 5\right)\,dx\,dy\text{.}\)
🔗
Solution. (Integrate with respect to \(x\) first, treating \(y\) as a constant and using FTC II; the result is a function of \(y\text{.}\) Then integrate that with respect to \(y\text{.}\))
