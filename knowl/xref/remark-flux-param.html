Remark 2.10.11.

If the surface \(S\) is parametrized with respect to \(u\) and \(v\text{,}\) we can write the unit normal vector as \(\hat{\mathbf{n}} = \dfrac{\mathbf{r}_u \times \mathbf{r}_v} {\lVert \mathbf{r}_u \times \mathbf{r}_v \rVert}\text{,}\) which can be combined with the fact that \(d\sigma = \lVert \mathbf{r}_u \times \mathbf{r}_v \rVert\, du\, dv\) (from (2.10.2)) to write the surface integral as
🔗
\begin{align} \amp \iint_S \mathbf{F} \cdot \hat{\mathbf{n}}\, d\sigma\notag\\ \amp = \underline{\hspace{4cm}},\tag{2.10.6} \end{align}
where \(R\) is the region of the parameters in the \(uv\)-plane. The normalizing length cancels against the area factor, which is what makes this formula so computable.
