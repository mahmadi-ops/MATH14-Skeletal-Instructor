Theorem 1.5.14. Conservative Fields are Gradient Fields.

Let \(\mathbf F = M\mathbf i + N\mathbf j + P\mathbf k\) be a vector field whose components are continuous throughout an open connected region \(D\) in space (Definition 1.5.4). Then \(\mathbf F\) is conservative if and only if \(\mathbf F\) is a gradient field \(\nabla f\) for a differentiable function \(f\text{.}\)
🔗
🔗

Proof.

(Gradient implies conservative: assume \(\mathbf F = \nabla f\) and apply Theorem 1.5.6 to any piecewise smooth curve from \(A\) to \(B\text{;}\) what does the answer depend on? Conservative implies gradient: fix a point \(A_0\) of \(D\) and define \(f(x,y,z)\) as the line integral of \(\mathbf F\) from \(A_0\) to \((x,y,z)\) along any curve in \(D\text{;}\) say why connectedness and path independence make this definition meaningful. To show \(\partial f/\partial x = M\text{,}\) compare \(f(x+h,y,z)\) with \(f(x,y,z)\) by travelling along the straight segment \(L_h\) from \((x,y,z)\) to \((x+h,y,z)\text{,}\) which lies in \(D\) because \(D\) is open; parametrize \(L_h\text{,}\) so that the difference quotient becomes an average of \(M\) over the segment, and let \(h \to 0\) using the continuity of \(M\text{.}\) The other two partials are the same argument.)
