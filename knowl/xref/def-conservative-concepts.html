Definition 1.5.4. Open, Connected, and Simply Connected Regions; Conservative Fields.

  • A region \(D\) is open if for every point \(P\) in \(D\) there is a disk with center \(P\) that lies entirely in \(D\text{,}\) which means that \(D\) doesn’t contain any of its boundary points.
    🔗
    🔗
  • Consider an open region \(D\) in space and a vector field \(\mathbf F\text{.}\) If the result of the line integral \(\int_C \mathbf F\cdot d\mathbf r\) from \(A\) to \(B\) is the same for all possible paths inside \(D\text{,}\) then the line integral \(\int_C \mathbf F\cdot d\mathbf r\) is said to be path-independent inside \(D\) and the field \(\mathbf F\) is said to be conservative on \(D\text{.}\)
    🔗
    🔗
  • If a vector field \(\mathbf F\) can be written as \(\mathbf F = \nabla f\text{,}\) where \(f\) is a scalar-valued function, then \(f\) is a potential function.
    🔗
    🔗
  • Piecewise smooth curves are curves that are made up of finitely many smooth pieces.
    🔗
    🔗
  • An open region \(D\) is said to be connected if any two points in \(D\) can be joined by a smooth curve that lies in the region.
    🔗
    🔗
  • \(D\) is simply connected, which means that every loop in \(D\) can be contracted to a point in \(D\) without ever leaving \(D\text{.}\) (See Figure 1.5.5.)
